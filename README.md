# 🎬 IMDB Sentiment Analysis — Streamlit Web App

This project performs **sentiment analysis on IMDB movie reviews** using Natural Language Processing (NLP) and Machine Learning.

## ✅ Features
- Classifies reviews as **Positive / Negative**
- Text preprocessing (tokenization, stopword removal, stemming)
- TF-IDF based feature extraction
- Uses **Naive Bayes** classifier (high accuracy & fast)
- Hosted as a **Streamlit web app** for real-time prediction
